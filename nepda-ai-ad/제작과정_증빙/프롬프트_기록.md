# AI 제작 과정 기록

- 사용 AI: Anthropic Claude (Claude Code) — 출력물의 상업적 이용 가능
- 제작일: 2026-10-02

## 1. 입력 프롬프트 (사용자 → AI)

```
https://blog.naver.com/naverofficial/224421149097

이 경진대회 나갈건데 영상 만들어줘
```

## 2. AI 작업 단계

1. **공고 분석**: 공고문을 읽고 출품 규격 정리 (5~30초, 9:16/16:9, mp4 500MB 이하, KV 1회 이상 사용, 해시태그, 심사 기준: AI 기술 활용도·메시지 전달력·창의성)
2. **공식 KV 분석**: `[넾다세일 AI 광고제] KV 가이드.psd`를 레이어 단위로 분석
   - 로고 스마트 오브젝트 안의 **벡터 원본**을 꺼내 4224px 고해상도로 렌더
   - 로고를 '넾' / '다' / '세일' 글자 조각으로 분리 (조립 애니메이션용)
   - KV 배너와 브랜드 컬러 #FFFFFF / #00F550 / #9162FF 추출
3. **브랜드 리서치**: '넾' = 네이버플러스를 한 글자로 압축한 이름이라는 점 확인 → 핵심 연출 아이디어로 사용
4. **콘셉트 & 카피**: 「장바구니 폭발」 — 장바구니에 담아만 둔 고민 → 거대한 혜택 폭발 → 장바구니를 비울 시간
5. **모션그래픽 생성**: AI가 작성한 Python 코드(`render.py`)로 600프레임 전부를 렌더링
   - KV의 폭발(스파이크) 모티프를 절차적으로 재구성, 아이콘(셔츠·립스틱·폰·머그·사과·쿠폰·선물·쇼핑백·태그)도 코드로 드로잉
6. **사운드 생성**: AI가 작성한 `audio.py`로 120BPM 음악과 효과음(킥·클랩·베이스·임팩트·라이저·코인음)을 합성 — 외부 음원 미사용
7. **검수 & 수정**: 정지컷을 렌더해 AI가 직접 확인하고 수정
   - "네이버플러스" 텍스트가 화면 밖으로 넘침 → 크기 조정
   - "혜택이 찾아온다!" 가독성 → 검정 띠 스타일로 변경
   - '다' 글자 조각이 'ㄷ'만 잘림 → 로고를 연결 요소 단위로 다시 분리
   - 엔드카드 장식이 카피를 가림 → 제거
8. **최종 출력**: 1080×1920, 30fps, 20초, H.264/AAC, 라우드니스 약 -15.5 LUFS

## 3. 첨부 자료

- `storyboard.png` — 전체 장면 스토리보드 (AI 렌더 프레임)
- `frames/` — 시점별 프레임 캡처
- `../render.py`, `../audio.py` — 영상/사운드를 생성한 AI 작성 코드

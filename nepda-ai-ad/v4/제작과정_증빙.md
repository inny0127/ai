# AI 제작 과정 기록 — 「혜택 하나」 (v4)

> **이 모자이크는 존재하지 않습니다.**
> 선물상자 82,944개, 하나하나가 독립된 3D 오브젝트입니다. Claude Code가 코드로 한 개씩 떨어뜨려 놓았어요.
> 상자 하나에서 시작해 넾다세일 KV가 되고, 82,944개의 뚜껑이 터지면 상자 속에 숨어 있던 날짜가 드러납니다.

- 사용 AI: Anthropic Claude (Claude Code) — 출력물 상업적 이용 가능
- 제작: AI가 **Three.js(WebGL) + Web Audio**로 장면·물리·카메라·사운드를 전부 코드로 작성
- 렌더: GPU 없는 서버에서 헤드리스 크로미움(SwiftShader)으로 1/30초 단위 결정적 렌더 → 780 프레임 → H.264
- 외부 스톡 이미지·영상·음원·3D 모델 **0%** (공식 KV 로고/배너만 사용)

## 2. 콘셉트

- 레퍼런스(코드로 타일 127,445개를 놓아 만든 3D 모자이크)를 분석한 뒤, 넾다세일의 공식 캠페인 문구
  **"쓰면 쓸수록 커지는 혜택"**([브랜드브리프](https://www.brandbrief.co.kr/news/articleView.html?idxno=9167))을 물리적으로 구현했습니다.
- **모자이크의 픽셀 하나하나 = 선물상자(혜택) 하나.** 상자 1개에서 시작해 82,944개가 모여 공식 KV가 됩니다.
- **두 겹의 그림**: 뚜껑은 KV(A)를, 몸통은 날짜 그림(B)을 그립니다. 82,944개의 뚜껑이 터지면 상자 속에 숨어 있던 "10.26 ~ 11.8"이 드러나요.
  저각 숏에서는 뚜껑 틈으로 초록 몸통이 미리 살짝 보이는 복선도 있습니다.

## 4. 기술 메모 (GPU 없이 8만 개를 그리기 위한 설계)

- **하이브리드 LOD**: 가까운/움직이는 상자는 진짜 3D 인스턴스(리본·매듭·그림자·광택), 멀리 깔린 상자는
  같은 PBR 조명을 받는 셀 셰이더로 그림. 저각 다이브와 폭발 구간(11.4~16.6초)은 82,944개 전부를 진짜 3D로 렌더
- 상자마다 낙하 높이·기울기·바운스·회전 지터, 뚜껑마다 발사 속도·회전축·각속도가 다른 결정적 물리
- 자체 후처리: 깊이 기반 피사계심도, FXAA, Khronos PBR Neutral 톤매핑, 그레인, 비네트, 폭발 순간 색수차
- 사운드: 82,944개 착지와 82,944개 펑의 실제 시각·좌우 위치에 샘플 단위로 맞춰 합성 + Web Audio 음악

# 넾다세일 AI 광고제 출품작 — 「장바구니 폭발」

- 파일: `넾다세일_AI광고_9x16.mp4`
- 규격: 1080×1920 (9:16), 30fps, **20초**, H.264 + AAC, 약 7.7MB
- 공모전 규격(5~30초, 9:16, mp4, 500MB 이하) 충족 ✅
- 공식 키비주얼(`KV 가이드.psd`)의 **로고 · KV 배너 · 컬러(#FFFFFF / #00F550 / #9162FF)** 사용 ✅

## 콘셉트

"장바구니에 담아만 두고 고민 중인 사람"에게 **거대한 혜택이 쾅! 하고 터지는** 15~20초 숏폼.
'넾'이 **네이버플러스**를 한 글자로 압축한 이름이라는 점을 살려, "네이버플러스" 글자가 찌그러지며
'넾'이 되고 → '다' → '세일'이 꽂히며 공식 로고가 완성되는 연출이 핵심입니다.

| 시간 | 장면 | 카피 |
|---|---|---|
| 0~3s | 어두운 화면, 흔들리는 장바구니, 물음표가 늘어남 | 장바구니에 / 담아만 두고 / 아직 고민 중? |
| 3~5.5s | 화이트 플래시 + KV 스타일 폭발 배경 | 쾅! → 거대한 / 혜택이 찾아온다! |
| 5.5~10s | "네이버플러스" 압축 → 넾 → 다 → 세일 → 공식 로고 | 넾 = 네이버플러스 / 거대한 혜택이 찾아온다! |
| 10~15s | 비트에 맞춘 카테고리 컷 → 쿠폰·선물·쇼핑백이 쏟아짐 | 패션도 뷰티도 디지털도 리빙도 식품도 → 다~ 세일! |
| 15~20s | **공식 KV 배너**가 떨어지며 꽂히는 엔드카드 | 이제 장바구니를 비울 시간! / 10.26 ~ 11.8 / 네이버플러스 스토어에서 만나요 |

- 사운드: 120BPM 비트, 컷·임팩트와 프레임 단위로 싱크. **음악·효과음 전부 코드로 직접 합성**한 것이라 외부 음원 저작권 문제가 없습니다.
- 첫 3초 훅 → 브랜드 → 혜택 → 기간/CTA 구조라 숏폼(릴스·쇼츠·틱톡)에 맞춰져 있습니다.

## 다시 렌더링하기

```bash
pip install pillow numpy scipy aggdraw
python3 render.py            # → out/nepda_ai_ad_9x16.mp4
python3 render.py --stills   # → out/stills/*.png (정지컷)
```

`assets/`: 공식 KV PSD에서 추출한 로고(벡터 원본을 고해상도로 렌더)·배너,
폰트는 상업적 이용이 가능한 OFL 라이선스(Pretendard, Black Han Sans)입니다.

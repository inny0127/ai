### 콘셉트

넾다세일 공식 브랜딩 콘셉트 **"쇼핑할수록 혜택이 점점 커진다"**를 그대로 영상으로.
선물상자(=혜택) 하나가 **기원전 암각화 → 조선 민화 장터의 '덤' → 77년 신문광고 → 86년 실크스크린 포스터 →
97년 브라운관 홈쇼핑 → 03년 픽셀 쇼핑몰 → 14년 플랫 UI 앱**을 끊김 없이 날아가며 화풍이 바뀌고, 점점 커집니다.
하단 '혜택 크기' 게이지가 ×1 → ×10,000 → **"측정 불가!!"**. 2026년, 너무 커진 혜택이 액자를 부수고 폭발 →
넾·다·세일 로고가 꽂히고 → 공식 KV가 '갤러리의 마지막 작품'으로 걸리며 끝납니다.

|---|---|---|

### 출품서 'AI 활용 / 제작 과정' 작성 예시

> 생성형 AI(Anthropic Claude)에 공모전 공고와 레퍼런스 영상을 주고 영상을 요청했습니다.

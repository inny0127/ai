# AI 제작 과정 기록 — 「혜택의 진화」

- 사용 AI: Anthropic Claude (Claude Code) — 출력물 상업적 이용 가능
- 제작 방식: AI가 작성한 **JavaScript(Canvas 2D + Web Audio)** 코드가 영상의 모든 프레임과 사운드를 실시간 생성
- 렌더링: 헤드리스 크로미움에서 1/60초 단위로 결정적(deterministic) 렌더 → 1,560 프레임 → H.264
- 외부 스톡 이미지·영상·음원·샘플 **0%** (공식 KV 로고/배너만 사용)

## 2. AI 작업 단계

1. **공고·KV 분석** — 출품 규격 정리, PSD에서 로고 벡터 원본 추출 → '넾/다/세일' 글자 조각 분리
2. **레퍼런스 분석** — 예시 영상(한 캐릭터가 20개 화풍을 끊김 없이 통과)을 프레임 단위로 분석
3. **콘셉트 도출** — 넾다세일 공식 브랜딩 콘셉트 "쇼핑할수록 혜택이 커진다"를 시각화:
   선물상자(=혜택)가 5,000년 쇼핑의 역사를 통과하며 점점 커지다 2026년에 액자를 부수고 폭발
4. **8개 화풍 일러스트를 전부 코드로 드로잉**
   | # | 시대 | 화풍 | 디테일 |
   |---|---|---|---|
   | 01 | 기원전 | 암각화 | 바위 질감 절차 생성, 쪼아 새긴 점선(펙킹), 반구대 고래, 물물교환하는 사람(8fps 스톱모션) |
   | 02 | 조선 | 민화 | 한지 섬유, 청록산수, 소나무·까치·모란, 장터 '덤' 애니메이션, **조각보 보따리** 주인공, 낙관 |
   | 03 | 1977 | 신문 광고 | 누런 신문지, 하프톤 사진, 한자 '大賣出' 도장 연출, 날짜 이스터에그(10月26日~11月8日) |
   | 04 | 1986 | 실크스크린 포스터 | 회전 선버스트, 멤피스 도형, 리소 인쇄 어긋남(미스레지스트레이션), 그레인 |
   | 05 | 1997 | 브라운관 홈쇼핑 | 레이스 덮인 TV, 생방송 자막, 남은 수량 카운트다운, VHS 트래킹 노이즈·스캔라인 |
   | 06 | 2003 | 픽셀 웹 | 240×300 저해상도 캔버스, 갈무리 픽셀폰트, 전광판, 커서 클릭 → 쿠폰 팝업 |
   | 07 | 2014 | 플랫 UI | 롱섀도, 모바일 앱, 푸시 알림 낙하, 좋아요 +1 |
   | 08 | 2026 | 넾다세일 KV | 공식 컬러의 폭발 스파이크, 상자가 커지며 액자 균열 → 화면 파편화 |
5. **연출** — 갤러리 인트로 → 썸네일 줌인 → 카메라 패닝(모션블러) → 시대 경계에서 주인공 화풍이 반씩 갈라지며 전환 →
   하단 '혜택 크기' 게이지 ×1 → ×10,000 → "측정 불가!!" → 폭발 → 넾·다·세일 로고 조립 → 카드 플립 → 공식 KV 엔딩
6. **사운드** — Web Audio API로 합성. 시대마다 장르 변화:
   원시 북·피리 → 장구·가야금(Karplus-Strong 현 모델링)·꽹과리 → 트로트 쿵짝·아코디언 → 80s 신스팝 →
   홈쇼핑 징글 → 칩튠(+모뎀음) → 트로피컬 하우스 → 빌드업 → EDM 드롭(넾·다·세·일 4음 훅)
7. **검수** — 정지 프레임을 렌더해 AI가 직접 확인하며 수정 (예: 80s 포스터에서 주인공이 배경에 묻힘 → 원 색상 변경, 게이트 스네어 고역 과다 → 필터 추가)

## ★ 메인: 「혜택 하나」 (v4)

> 이 모자이크는 존재하지 않습니다. 선물상자 82,944개, 하나하나가 독립된 3D 오브젝트이고, Claude Code가 코드로 한 개씩 놓았습니다.

- 파일: `넾다세일_혜택하나_9x16.mp4`
- 규격: 1080×1920 (9:16), 30fps, 26초, H.264 + AAC — 공모전 규격(5~30초, mp4, 500MB 이하) 충족
- 공식 KV(로고 · 배너 · 컬러) 사용 ✅
- 제작: Three.js(WebGL) + Web Audio로 장면·물리·카메라·사운드를 전부 코드로 생성 → `v4/`
- 제작 과정·기술 메모: `v4/제작과정_증빙.md`

### 콘셉트

넾다세일 공식 캠페인 문구 **"쓰면 쓸수록 커지는 혜택"**을 물리적으로 구현했습니다.
모자이크의 픽셀 하나하나가 **선물상자(혜택) 하나**예요. 상자 1개로 시작해 82,944개가 모이면 공식 KV가 됩니다.
그리고 **82,944개의 뚜껑이 동시에 터지면**, 상자 속에 숨어 있던 두 번째 그림 "10.26 ~ 11.8"이 드러나요.

| 시간 | 장면 |
|---|---|
| 0~3s | 매크로: 선물상자 하나가 붉은 분필 밑그림 위에 '톡' — "혜택 하나." |
| 3~11.4s | 상자가 쏟아지며 카메라가 142배 후퇴, KV 모자이크 완성 — "쓰면 쓸수록 / 커지는 혜택", 카운터 82,944개 |
| 11.4~13.45s | 거대한 로고 속으로 저각 다이브, 뚜껑들이 덜컹거림 |
| 13.5s | **펑** — 82,944개 뚜껑이 분수처럼 솟구쳐 렌즈를 스침 |
| 14.5~20.5s | 크레인업 → 상자 속 날짜 공개 — "10월 26일, 혜택이 열린다" |
| 20.8~26s | 공식 KV 엔딩 카드 + 10.26 ~ 11.8 + 네이버플러스 스토어 |

### 출품서 'AI 활용 / 제작 과정' 작성 예시

> 생성형 AI(Anthropic Claude)가 Three.js와 Web Audio 코드를 작성해, 독립된 3D 선물상자 82,944개를 한 개씩 떨어뜨려
> 넾다세일 KV 모자이크를 만들고, 82,944개의 뚜껑이 터지며 상자 속 두 번째 그림(행사 기간)이 드러나도록 연출했습니다.
> 상자마다 낙하·바운스·회전, 뚜껑마다 발사 궤적이 다른 물리 시뮬레이션이고, 착지음과 '펑' 소리도 각 상자의 실제 시각에 맞춰 합성했습니다.
> 공식 KV 로고는 PSD의 벡터 원본에서 추출했고, 외부 스톡 이미지·영상·음원·3D 모델은 쓰지 않았습니다.
> 증빙: 프롬프트 기록, 렌더링 코드 전체, 스토리보드 (`v4/제작과정_증빙.md`)

## v3: 「혜택의 진화 — 네이버 쇼핑 2003 → 2026」

- 규격: 1080×1920 (9:16), **60fps**, 26초, H.264 + AAC — 공모전 규격(5~30초, mp4, 500MB 이하) 충족
- 공식 KV(로고 · 배너 · 컬러) 사용 ✅

- 연혁 사실과 출처: `v3/제작과정_증빙.md`

### 콘셉트

넾다세일 브랜딩 "쓰면 쓸수록 커지는 혜택"을 **네이버 쇼핑의 실제 23년 역사**로 증명합니다.
선물상자(=혜택) 하나가 네이버 쇼핑의 주요 순간을 끊김 없이 날아가며, 장면마다 **그해의 디자인 트렌드**로 화풍이 바뀌고 점점 커집니다.

| 시간 | 장면 (실제 연혁) | 화풍 | 사운드 |
|---|---|---|---|
| 0~2s | 갤러리 인트로 "혜택의 진화" → 첫 작품으로 줌인 | — | 바이닐 + 오르골 |
| 2~4s | 2003.10 지식쇼핑 · 200여 개 쇼핑몰 가격비교 | 픽셀 웹 | 폴리포닉 벨소리 |
| 4~6s | 2012.3 샵N · 판매자가 직접 여는 상점 | 스큐어모피즘 | 일렉트로팝 |
| 6~8s | 2014.6 스토어팜 · 누구나 무료로 입점 | 플랫 일러스트 | 우쿨렐레 |
| 8~10s | 2015.6 네이버페이 · 100일 만에 결제 3,000만 건 | 롱섀도 플랫 | 트로피컬 하우스 |
| 10~12s | 2018.2 스마트스토어 · 데이터·통계 | 머티리얼 | 퓨처베이스 |
| 12~14s | 2020 멤버십 + 쇼핑라이브 | 네온 | 로파이 |
| 14~16s | 2025.3 네이버플러스 스토어 · AI 추천 | 글래스모피즘 | 앰비언트 트랩 |
| 16~17.5s | 2025.10 첫 넾다세일 · 2주 만에 1조 원 → "그리고 2026, 더 거대하게!" | KV | 빌드업 |
